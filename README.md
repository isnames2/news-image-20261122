A Python program that draws a newspaper front page summing up the world news of Sunday 22 November 2026 and writes it to entry.png.

All artwork and text are drawn in code with a built-in 5×7 pixel font; no external assets, no network. The program is deterministic: every run writes the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
